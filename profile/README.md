# Transparency Project

Software Supply Chains are increasingly prone to supply chain attacks. As a result, the industry is moving towards zero trust,
meaning "Trust but Verify". An excellent way to establish "zero trust", is to make the delivery of Software Components transparent.

Transparency provides an augmented trust view of the Software Deliverable by publishing the claims about the software,
by the Software Publisher in an Append ONLY Log. 
The Claims about the Software published to a Log can be cryptographhically Verified (both offline and online).

The Log can be monitored by designated actors (such as Monitors and Witness) who constantly observe the log for proper behaviour,
by checking the consistency of log operation.

The repositories in this organization is a Work In Progress Proof of Concept Demonstration of
Transparency Principles, specifically for Firmware(s) which are part of Trusted Computing Base (TCB) of 
the Confidential Computing Environment.
